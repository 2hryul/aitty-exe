## 2026-04-24 작업 내역

### 작업 내용

### 결정 사항

1. **프리셋 암호 기반 전환 (요청 3건 반영)**
   - 초기: MachineGuid + 앱 salt + 파일 salt → PBKDF2 (PC 바인딩)
   - **최종: 사용자 입력 password + 앱 salt + 파일 salt → PBKDF2** (PC 이동 가능, 파일 공유 가능)
   - 복호화 실패 시 `Decrypt`가 `null` 반환 → 로드 핸들러는 **세션 변경 없이** 에러만 반환 (이전 방식은 API 키만 빈 값으로 조용히 적용되어 "설정 오기가 안된다" 증상)

2. **Custom Base URL에서도 스트리밍 우선 시도**
   - 최초: Shinhan Hands 게이트웨이 SSE 미지원 추정 → 커스텀 URL이면 무조건 non-stream으로 분기하는 안 검토
   - 사용자 지시 후 변경: "게이트웨이가 SSE 지원하는 경우도 있으니 일단 스트리밍으로 시도" → **스트리밍 1차 시도 → 빈 응답이면 non-stream 1회 폴백** 구조로 수정. SSE 본문은 `ai_api.log`에 캡처하여 사후 진단 가능

3. **LiteLLM 모델 제약 자동 교정**
   - 401 응답 본문의 `"This token can only access models=['Qwen3.5-9B']"` 패턴 정규식 감지 → 전체 허용 목록을 `_discoveredModels`에 저장 → 첫 번째 모델로 교체 후 1회 재시도 + ListModelsAsync가 이 목록 반환 → 드롭다운 자동 채움

4. **구형 WebView2 드래그 폴백**
   - `IsNonClientRegionSupportEnabled`가 v117 이상에서만 지원 → 이전 버전에서 `InvalidCastException` → 창이 중앙 고정되어 이동 불가
   - 예외 catch에서 `_useWpfDragFallback=true` 설정 → `PreviewMouseLeftButtonDown`이 top 36px 영역(우측 140px 버튼 제외)에서 `DragMove()` + 더블클릭으로 Maximized 토글

5. **UI 재배치 (요청 3건)**
   - 체크박스 각각 독립 행 분리 (라벨 가독성)
   - 저장/로드/삭제 버튼을 프리셋 드롭다운 같은 행에 통합
   - 💾 저장 버튼은 Apply 성공(`isApplySuccess === true`) 상태에서만 활성화 유지

6. **버전 정책**: v0.3.0으로 MINOR 올림 — 하위 호환 기능 추가(기존 프리셋 파일은 호환 안 되지만 사용자 재입력으로 해결 가능)

### 미완료 / 다음 작업

- **초기 로딩 속도 개선**: 원인 파악 완료(`EnableCompressionInSingleFile=true`로 인한 .NET 런타임 추출 3~8초, React 단일 번들 1.37MB 파싱). 사용자 판단으로 이번 릴리즈에서는 수정 보류.
- **체감 품질**: non-stream 폴백 시 응답이 21초 후 일괄 출력 → 후속 개선 여지(pseudo-streaming 단어 분할 에미션)
- **PC 이동 테스트**: 이번 암호 기반 전환 이후 실제로 PC A → PC B 파일 복사 + 동일 암호 복구 검증 필요 (사용자 테스트 예정)

### 이슈 / 특이사항

- **Shinhan Hands 게이트웨이 특성**
  - 200 OK + 빈 SSE 스트림 (vLLM + LiteLLM + istio 조합)
  - Postman 검증: `stream=false` + `max_tokens` 명시 조합만 안정적 → `BuildRequestBody`에 `max_tokens: 4096` 주입
  - 응답 헤더: `x-envoy-upstream-service-time`, `x-litellm-version: 1.48.2`, `Cruz-Engine` 에러 패턴 → 게이트웨이 감지 로그/UI 힌트 배너

- **파일 잠금**: `Aitty.exe` 실행 중 publish 시 DLL lock → `taskkill //F //IM Aitty.exe` 선행 필요

- **인스톨러 WebView2**: 1.6MB 부트스트래퍼(인터넷 필요) → 186MB standalone으로 교체해야 격리 PC에서도 WebView2 신규 설치 가능

- **crossorigin 속성**: Vite 7은 `<script>`/`<link>`에 `crossorigin` 자동 삽입 → WebView2 가상호스트 매핑에서 스크립트 로드 차단. 빌드 시 PowerShell로 제거(csproj `BuildReactApp` 타겟) + 런타임 읽기 전용 위치(Program Files 설치) 대비 try-catch

- **버전 파일 경고**: VERSION/setup.iss가 LF 저장되어 Git이 CRLF 경고 표시 — 동작 무관
