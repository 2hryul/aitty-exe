## 이슈 1: "신한DS AX본부" 미표시

### 원인 분석 (2단계)

#### 원인 A — 빌드 파이프라인 결함

```
.csproj BuildReactApp 타겟:
  Condition: SkipReactBuild != true
  동작: npm run build → robocopy webapp\dist → src\Aitty\wwwroot
```

`-p:SkipReactBuild=true`로 publish 시 **npm build와 robocopy가 동시에 스킵**됨.
React 코드를 별도로 `npm run build` 해도 wwwroot에는 **구버전 JS가 남아있음**.

| 위치 | 파일 해시 | 상태 |
|------|----------|------|
| `dist/publish/wwwroot/assets/` | `index-DtsYNmvz.js` | 구버전 (수정 전) |
| `webapp/dist/assets/` | `index-cOT4UwIs.js` | 신버전 (수정 후) |

#### 원인 B — 텍스트 대소문자 오류

코드: `const org = '신한DS Ax본부'`
요구: `신한DS AX본부` (AX 대문자)

### 수정 계획

| 단계 | 파일 | 수정 내용 |

## 이슈 2: SSH exit 후 Connected 상태 유지

### 원인 분석 (심층)

**`exit` 후 SSH 프로토콜 상태:**

```
[T+0.0s] 사용자 입력: exit
[T+0.1s] 원격 셸 종료 → 채널 EOF + CLOSE 전송
[T+0.1s] _shellStream: CanRead=true(!), DataAvailable=false
[T+0.1s] _client: IsConnected=true (TCP 아직 살아있음)
[T+4.0s] 헬스체크 → PingAlive → SendKeepAlive() → 성공 (TCP 존속)
[T+4.0s] isConnected=true → UI 변경 없음
[T+15s] KeepAlive 자동 전송 → 서버 응답 없음 → IsConnected=false (지연 감지)
```

**핵심 문제:**
- `ShellStream.CanRead` → 항상 `true` 반환 (Stream의 capability 플래그, 상태 플래그 아님)
- `SendKeepAlive()` → SSH 전송 계층(SSH_MSG_IGNORE) 전송, 셸 채널 상태와 무관
- 서버가 TCP를 즉시 끊지 않으면 최대 15초(KeepAlive 간격)까지 미감지

### 수정 계획 (다층 감지)

4가지 레이어로 셸 종료를 감지:

#### Layer 1 — 출력 패턴 감지 (즉시)
**파일:** `SshService.cs` — `ReadFromShell()`

```
"logout" 또는 "Connection to ... closed" 패턴 감지 시
→ _state.IsConnected = false (즉시)
```

셸 종료 시 마지막 출력이 "logout"인 점을 활용. 단독 출력일 때만 감지하여 오탐 최소화.

#### Layer 2 — Read 예외 처리 강화 (즉시)
**파일:** `SshService.cs` — `ReadFromShell()` catch 블록

현재: `catch { return null; }` → 상태 미갱신
수정: `catch { _state.IsConnected = false; return null; }`

#### Layer 3 — 셸 쓰기 프로브 (4초 이내)
**파일:** `SshService.cs` — `PingAlive()`

SendKeepAlive 전에 셸 스트림 쓰기 시도:
```csharp
lock (_streamLock)
{
    _shellStream.WriteByte(0);  // 채널 닫혔으면 예외 발생
}
```
채널이 닫힌 후 Write 호출 → SSH.NET이 `ObjectDisposedException` / `SshConnectionException` 발생 → catch에서 _state.IsConnected = false.

#### Layer 4 — SSH 전송 KeepAlive (기존, 백업)
`SendKeepAlive()` — TCP 끊김 감지 (최후 방어선)

### 헬스체크 주기 조정
**파일:** `SSHTerminal.tsx`

`HEALTH_CHECK_INTERVAL`: 4,000ms → 3,000ms (더 빠른 주기)
