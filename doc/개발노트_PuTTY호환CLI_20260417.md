# 개발노트 — PuTTY 호환 CLI 인자 지원 (HiWare 연동)

## 2026-04-17 작업 내역

- 작업 내용:
  - PuTTY 호환 CLI 인자 파서 신규 구현 (`PuttyArgParser.cs`)
  - WPF App.xaml.cs에 OnStartup 오버라이드 추가 → CLI 인자 파싱
  - IpcHandler에 `cli:get-connection` / `cli:auto-connect` IPC 핸들러 추가
  - React 프론트엔드에 CLI 자동접속 flow 구현 (ipcBridge, App.tsx, SSHTerminal)
  - 비밀번호가 IPC 브릿지를 넘지 않도록 C# 메모리 내 직접 접속 방식 채택

- 변경 파일:
  - `src/Aitty/Services/PuttyArgParser.cs` (신규)
  - `src/Aitty/App.xaml.cs`
  - `src/Aitty/MainWindow.xaml.cs`
  - `src/Aitty/Ipc/IpcHandler.cs`
  - `webapp/src/bridge/ipcBridge.ts`
  - `webapp/src/App.tsx`
  - `webapp/src/components/SSHTerminal.tsx`

- 결정 사항:
  - PuTTY 표준 CLI 인자 형식 채택 (`-ssh`, `-P`, `-l`, `-pw`, `-i`, `[user@]host`)
  - `-pw` 비밀번호 인자는 HiWare PSM 연동 시 불가피하므로 지원하되, 보안 경고 코멘트 포함
  - 비밀번호는 C# `App.StartupConnection` → `IpcHandler._startupConnection`에만 보관, 프론트엔드로 전달하지 않음
  - `cli:auto-connect` IPC 핸들러가 `SshService.ConnectAsync()`를 직접 호출하여 비밀번호 노출 차단
  - 자동접속 실패 시 접속 폼에 host/port/username 사전입력 후 폴백
  - timeout은 기본 30초 (`REQUEST_TIMEOUT`) — IPC 브릿지 기존 설정 활용

- 미완료/다음 작업:

## 지원 CLI 인자

| 인자 | 설명 | 예시 |
|------|------|------|
| `[user@]host` | 위치 인자 | `admin@192.168.1.100` |
| `-ssh` | SSH 강제 (플래그만) | `-ssh` |
| `-P port` | 포트 (대문자 P) | `-P 2222` |
| `-l username` | 사용자명 | `-l admin` |
| `-pw password` | 비밀번호 | `-pw secret` |
| `-i keyfile` | 개인키 경로 | `-i C:\keys\server.ppk` |

## 테스트 명령어

```powershell
# 일반 GUI 모드
.\Aitty.exe

# 기본 접속
.\Aitty.exe admin@192.168.1.100

# 전체 PuTTY 인자
.\Aitty.exe -ssh -l admin -P 2222 -pw secret 192.168.1.100

# 키 인증
.\Aitty.exe -i C:\keys\server.ppk -l admin host.example.com
```
