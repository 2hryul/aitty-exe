## 3. 핵심 수정 상세

### 3.1 AI Analyze 버튼 미동작

**원인**: `disabled={!isConfigured || isBusy}` — AI 미설정 시 버튼 자체가 비활성화되어 클릭 불가
**수정**:
- 버튼: `disabled={isBusy}` (항상 클릭 가능)
- `handleAnalyzeClick`에 early return 추가 — 미설정 시 경고 메시지 출력
- `useCallback` deps에 `isConfigured` 추가

### 3.2 SSH 폼 레이아웃

**변경 전**: HOST | PORT | USERNAME + Advanced(PASSWORD, PRIVATE KEY)
**변경 후**: HOST | PORT | USERNAME | PASSWORD | [Connect] + Advanced(PRIVATE KEY only)
**CSS**: `.ssh-form-grid` → `grid-template-columns: 1fr 60px 1fr 1fr auto`

### 3.3 ASCII 아트 배너 깨짐

**원인 1 (주)**: CSS `.xterm { font-size: 12px }` vs JS `Terminal({ fontSize: 13 })` 충돌
→ xterm.js 캔버스 렌더러는 JS config로 셀 크기 계산, CSS가 DOM에서 12px 덮어씌움
→ 셀 크기 불일치 → 문자 경계 넘침/잘림

**원인 2 (부)**: showBanner 문자열 자체의 정렬 오류 (S-H 경계, N-D 간격)

**수정**:
1. CSS에서 `font-size: 12px` 제거
2. pyfiglet(standard font) 기준으로 5줄 모두 재생성 (각 57자 정렬)

### 3.4 AI Settings 행 분리

**변경 전**: Check | Apply | Model | 시스템프롬프트 | 로그저장 (한 줄)
**변경 후**:
- 행 1 (`settings-button-row`): Check | Apply | Model dropdown
- 행 2 (`settings-option-row`): 시스템 프롬프트 버튼 | 로그저장 체크박스

### 핵심 수정 상세

#### #9 창 리사이즈 불가

**원인**: `WindowStyle="None"` + `WindowChrome`에서 WebView2 HWND가 리사이즈 테두리의 마우스 이벤트를 가로챔
**수정**: WebView2에 `Margin="4"` → 테두리 4px 영역이 WPF Grid에 노출 → WindowChrome이 리사이즈 감지

#### #11 SSH exit 미감지 (4-Layer 접근)

| Layer | 감지 방식 | 위치 |
|-------|----------|------|
| 1 | `logout` / `Connection to ... closed` 출력 패턴 | `ReadFromShell()` |
| 2 | ShellStream Read 예외 catch | `ReadFromShell()` |
| 3 | ShellStream Flush 프로브 | `PingAlive()` |
| 4 | SSH KeepAlive 전송 | `PingAlive()` |

#### #12 SSH 키 입력 딜레이

**원인**: 폴링 백오프(`POLL_INTERVAL_MAX=500ms`) — 키 입력 후에도 최대 500ms 대기
**수정**: `acceleratePolling()` 콜백 — `onData`에서 키 입력 즉시 폴링 간격을 50ms로 리셋, MAX를 200ms로 축소

#### #13 AI 채팅 자동스크롤 (3회 시도 후 해결)

**근본 원인**: 조건부 렌더링 — `messages.length === 0`일 때 `ref={scrollRef}` 없는 별도 `<div>` 반환 → `useEffect([], [])` 실행 시 `scrollRef.current = null` → wheel 이벤트 리스너 미등록 → 사용자 스크롤 감지 불가

| 시도 | 접근 | 결과 |
|------|------|------|
| 1차 | `scroll` 이벤트로 사용자 스크롤 감지 | 실패 — `scrollIntoView({ behavior: 'smooth' })` 애니메이션이 scroll 이벤트 발생시켜 race condition |
| 2차 | `wheel` 이벤트 + `scrollTop = scrollHeight` | 실패 — 조건부 렌더링으로 리스너 자체가 미등록 |
| 3차 | 단일 스크롤 컨테이너로 통합 | 성공 — `scrollRef` 항상 할당, wheel 리스너 정상 등록 |

**최종 수정**: 두 개의 return 분기 → 단일 `<div ref={scrollRef}>` 컨테이너, 빈 상태는 자식으로 렌더링

#### #14 SSH 폼 입력란 너비 축소

**원인**: `grid-template-columns: 1fr 60px 1fr 1fr auto` — `1fr`이 전체 너비 균등 분할
**수정**: `160px 55px 130px 130px auto` — 실제 입력값(IP, 포트, 유저명, 패스워드)에 맞는 고정 너비

### 결정 사항

- wheel 이벤트를 scroll 이벤트 대신 사용 (프로그래밍 스크롤과 사용자 스크롤 구분 가능)
- 스트리밍 스크롤은 `scrollTop = scrollHeight` (instant) — `scrollIntoView({ behavior: 'smooth' })` 대신 (애니메이션 중첩 방지)
- SSH 연결 감지는 4-Layer 다중 방어 (단일 방식으로는 모든 케이스 커버 불가)
- `#pragma warning disable CS0618` — SSH.NET의 `SendKeepAlive()` deprecated 경고 억제
