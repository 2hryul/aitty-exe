# 🎬 Aitty 시연 시나리오 — 2분 WOW 데모

**대상**: 시스템 엔지니어 + 임원 혼합 청중
**환경**: Anthropic Claude API + 테스트 Linux SSH 서버
**비중**: AI 기능 중심 80% / 보안·설치 20%
**버전**: Aitty v0.4.0

---

## 사전 준비

### 화면 설정
- 해상도 **1920×1080** 권장 (1280×720도 가능). Aitty 창 **거의 풀스크린**으로
- 폰트 크기는 OS 디스플레이 스케일 **125%** 권장 (캡쳐 후 가독성)
- 녹화 도구: OBS Studio / Windows Game Bar (Win+G) / ShareX

### Aitty 환경 사전 셋업 (녹화 전)
1. v0.4.0 설치 완료
2. AI Settings → Provider: **Anthropic Claude** + API 키 입력 → **Apply 미리 한 번** (모델 목록 5개 캐시되도록)
3. **프리셋은 저장하지 말고 시작** (저장 동작을 시연에서 보여줌)
4. 테스트 SSH 서버 정보 메모 (host/user/password 손에 들고)
5. 서버에 미리 큰 로그 하나 만들어두기:
   ```bash
   sudo tail -c 200000 /var/log/syslog > /tmp/demo.log
   ```

### 화면 정리
- 작업표시줄 아이콘 정리, 알림 끄기 (Focus assist ON)
- 데스크탑 배경 단색
- Aitty만 단독 표시

## 📜 장면별 상세 대본

### ▶ 장면 ① — 인트로 (0:00–0:15, **15초**)

**화면 동작:**
1. Aitty 실행 (스플래시/배너 등장)
2. SSH Terminal 탭 활성 — 큰 "SHINHAN DS" 블록 배너 노출
3. **2초 정지** — 청중이 화면 인식할 시간

**자막 (상단 오버레이):**
> **"Aitty — SSH + AI 통합 터미널"**
> 한 화면에서 접속부터 분석까지

**발화 (옵션, 음성 입힐 경우):**
> "기존 PuTTY로는 SSH 따로, ChatGPT 따로였습니다. Aitty는 둘을 하나로 합쳤습니다."

---

### ▶ 장면 ② — SSH + AI 명령 분석 ⭐ (0:15–0:50, **35초**)

**화면 동작:**
1. SSH 폼에 host/user/password 입력 → **Connect** (3초)
2. 서버 프롬프트 등장 → 다음 명령 차례로 입력:
   ```bash
   top -bn1 | head -20
   ```
3. 화면에 CPU/메모리/프로세스 출력됨 (5초간 표시)
4. **우측 상단의 `AI Analyze` 버튼 클릭** ⭐ (이게 핵심)
5. AI Chat 패널에 **즉시 스트리밍** 시작:
   - "위 출력을 보면 CPU는 X%, 메모리는 Y% 사용 중이며..."
   - "주의해야 할 프로세스는 [프로세스명]이고..."
   - "다음 단계로 권장하는 명령은 `iotop` 또는 ..."

**자막:**
> **"WOW #1: SSH 출력 → AI가 바로 해석"**
> 복사-붙여넣기 없이 한 번 클릭

**임원용 한 줄 자막 (하단):**
> 장애 분석 시간 ▼ 50%

**촬영 팁:**
- AI 스트리밍 응답이 타자치듯 나오는 효과 → 15초간 보여줘도 지루하지 않음
- 응답 중반에 **다음 장면으로 자연스럽게 전환** (전체 응답 끝까지 기다리지 말 것)

---

### ▶ 장면 ③ — 대용량 로그 자동 분할 ⭐⭐ (0:50–1:20, **30초**)

**화면 동작:**
1. 좌측 아이콘 사이드바에서 **📋 로그 탭** 클릭
2. "로그 파일 경로" 입력칸에 `/tmp/demo.log` 입력
3. **"요약" 모드 버튼** 클릭 → **실행**
4. 셸 출력 영역에 logcheck.sh 결과 출력 (2초간 표시)
5. 그 아래 "AI 분석" 버튼 클릭
6. AI Chat 패널이 **분할 분석** 모드 진입:
   - 화면에 "200KB 로그 → 4 청크로 분할 분석 중... (1/4)" 진행률 표시
   - "Claude haiku-4.5 예산 50KB 기준 자동 분할" 안내
7. 분석 결과 종합 표시 (10초간)

**자막:**
> **"WOW #2: 대용량 로그 자동 분할"**
> ChatGPT 토큰 한도 → Aitty가 알아서 처리

**임원용 한 줄 자막:**
> ChatGPT로 못 하는 200KB+ 로그도 한 번에

**촬영 팁:**
- 청크 진행률 (1/4 → 2/4 → ...) 표시되는 순간이 가장 인상적 — **이 부분 확실히 캡쳐**
- 분석 결과 텍스트는 짧게 보여주고 다음 장면으로 (자세히 읽을 시간 X)

---

### ▶ 장면 ④ — 위험 명령 차단 (1:20–1:40, **20초**)

**화면 동작:**
1. 다시 SSH Terminal 탭으로 돌아가기
2. 프롬프트에 다음 입력:
   ```bash
   rm -rf /
   ```
3. **🔴 빨간 모달 즉시 팝업**:
   - "🚨 차단된 명령"
   - "루트 파일시스템 삭제 (rm -rf /)"
   - "대안: rm -ri ./target"
4. **3초간 정지** (청중이 모달 읽을 시간)
5. 모달 닫고 정상 명령 입력:
   ```bash
   ls -la
   ```
6. 정상 실행 결과 (1초 표시)

**자막:**
> **"WOW #3: 위험 명령 사전 차단"**
> 40개 패턴 자동 평가 — 운영 사고 예방

**임원용 한 줄 자막:**
> 신입 SE 실수도 막아주는 안전 장치

**촬영 팁:**
- 빨간 모달이 등장하는 0.5초가 임팩트 — **풀스크린에서 모달이 큰 비율로 보이게**
- 정상 명령(`ls -la`)도 통과시켜서 "막무가내 차단 아님" 강조

---

### ▶ 장면 ⑤ — 프리셋 + 마무리 (1:40–2:00, **20초**)

**화면 동작:**
1. AI Settings 패널 열기 (펼침)

6. 탐색기 창에 `latest.log`, `api_*.log`, `ssh-audit.log` 표시 (3초)
7. Aitty 창으로 복귀
8. **최종 자막 + 페이드아웃**

**자막 (장면 내):**
