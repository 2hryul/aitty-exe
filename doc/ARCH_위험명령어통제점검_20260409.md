## 2. 수정 내역

### Phase 1: 정규식 패턴 수정 + CodeBlock 전체 검사

**`commandSafety.ts` 패턴 수정:**

| 수정 | 변경 전 | 변경 후 |
|------|---------|---------|
| Fork bomb | `:\(\)\s*\{.*:\|:.*\}` | `:\(\)\s*\{[^}]*:\s*\|\s*:` |
| shutdown | `\b(shutdown\|poweroff\|halt)\b` | `\b(poweroff\|halt)\b` + `\bshutdown\b(?!\s+(-c\|--cancel\|--help\|--version))` |
| reboot | `\breboot(\s\|$)` | `\breboot\b(?!\s+--(help\|version))` |
| 신규 | — | `\brm\s+.*--no-preserve-root` (danger) |

**`CodeBlock.tsx` 수정:**
- `checkCommandSafety(firstLine)` → `checkCommandSafety(code)` — 전체 코드블록 검사

### Phase 2: SSH 터미널 직접 입력 안전 검사

**`SSHTerminal.tsx` — 입력 버퍼 + Enter 인터셉트:**

```
키 입력 → lineBufferRef 축적 → Enter(\r) 시점에 checkCommandSafety()
├─ danger  → 차단 + ANSI 빨강 경고 + Ctrl+C(프롬프트 리셋)
├─ caution → ANSI 노랑 경고 + "yes" 확인 모드 진입
├─ warning → ANSI 노랑 경고 후 실행 허용
└─ safe    → 그대로 전달
```

**버퍼 추적 처리:**
- 일반 문자: 버퍼 축적
- Backspace: 마지막 문자 삭제
- Ctrl+C/U: 버퍼 초기화
- Ctrl+W: 마지막 단어 삭제
- 방향키(Escape 시퀀스): 버퍼 리셋 (history recall 검사 불가 — 수용)
- 멀티 문자 붙여넣기: `\r` 포함 시 라인별 검사
- 우클릭 붙여넣기: danger 시 차단

### Phase 3: 백엔드 방어 계층

**`CommandSafetyService.cs` (신규):**
- 치명적 패턴 7개 (rm -rf /, mkfs, dd, fork bomb, chmod 777 -R /) — Compiled Regex
- `IsDangerous(string command): bool`

**`IpcHandler.cs` 통합:**
- `ssh:exec` → `CommandSafetyService.IsDangerous()` 차단
- `ssh:shell:write` → data에 `\r\n` 포함 시 라인별 검사 (코드블록 Run 버튼 경유 캐치)

### Phase 4: 단위 테스트

**`commandSafety.test.ts` (신규) — Vitest 36개 전체 통과:**

| 분류 | 테스트 수 |
|------|----------|
| danger 패턴 정탐 | 16개 |
| shutdown/reboot 오탐 방지 | 5개 |
| caution 패턴 | 5개 |
| warning 패턴 | 2개 |
| safe 판정 | 5개 |
| 멀티라인 검사 (GAP-1 검증) | 4개 |

## 3. 방어 계층 구조 (수정 후)

```
Layer 1: 프론트엔드 CodeBlock (AI 코드블록)
  └─ checkCommandSafety(code) — 전체 코드 검사
  └─ danger: 버튼 비활성화 / caution: yes 확인 / warning: 배너

Layer 2: 프론트엔드 SSHTerminal (직접 입력)
  └─ 입력 버퍼 + Enter 인터셉트
  └─ 우클릭 붙여넣기 검사
  └─ danger: ANSI 차단 메시지 / caution: yes 확인 모드

Layer 3: 백엔드 IpcHandler (최후 방어선)
  └─ ssh:exec — CommandSafetyService.IsDangerous()
  └─ ssh:shell:write — 줄 단위 검사 (전체 명령 전송 시)
```

## 4. 알려진 한계 (수용)

| 한계 | 사유 |
|------|------|
| 방향키 히스토리 recall 검사 불가 | 서버 측 히스토리, 클라이언트 접근 불가 |
| Tab 자동완성 후 버퍼 불일치 | 서버 측 완성 결과 알 수 없음 |
| Shell alias 우회 가능 | 클라이언트 패턴매칭 고유 한계 |
