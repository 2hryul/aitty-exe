### 이슈 / 특이사항
- **로그에 노출된 Anthropic 키 폐기 완료** (Project Owner 처리). 본 패치는 앞으로의 노출만 차단하므로, 이미 기록된 키는 별도 폐기 필수였음.
- **Reviewer가 발견한 S-1 (Gemini URL 키 누락)이 본 batch의 핵심 보완** — 초기 브리프가 헤더 마스킹만 명시했으나, Gemini는 URL query 방식이라 별도 마스킹 필요. C-1과 동급 critical 누락이었음.
- **char[] 전환 시 `new string(pw)` 임시 카피본 한계** — SSH.NET이 string을 요구하고 라이브러리 내부에서 자체 카피본 생성. .NET string immutability + interning 위험으로 string 측 메모리는 완전 정리 불가. 우리 측 char[]만 0-overwrite하는 best-effort 전략임을 코드 주석에 명시.
- **Inno Setup AppVersion 동기화 미자동화** — 현재 4곳(VERSION/csproj/package.json/setup.iss) 수동 동기화. 다음 hardening 라운드에서 MSBuild `<Target>`으로 VERSION 파일 읽어 csproj/setup.iss 주입 자동화 후보.
