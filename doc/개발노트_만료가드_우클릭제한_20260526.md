### 변경 ① — 프로토타입 만료 가드
**파일:** `src/Aitty/App.xaml.cs`

- `PrototypeExpiry = 2026-10-25 23:59:59 (Local)` 정적 상수.
- `OnStartup` 진입부에서 `DateTime.Now > PrototypeExpiry` 체크 → 안내 MessageBox 후 `Shutdown()` + `return`.
- **base.OnStartup 전에** 처리 — StartupUri 기반 MainWindow 생성 자체 차단.
- 메시지: `"AItty 프로토타입으로 업데이트 서버 연결이 필요합니다."` (제목 `AItty`, MessageBoxImage.Information, OK 버튼)

```csharp
private static readonly DateTime PrototypeExpiry =
    new(2026, 10, 25, 23, 59, 59, DateTimeKind.Local);

protected override void OnStartup(StartupEventArgs e)
{
    if (DateTime.Now > PrototypeExpiry)
    {
        MessageBox.Show(
            "AItty 프로토타입으로 업데이트 서버 연결이 필요합니다.",
            "AItty", MessageBoxButton.OK, MessageBoxImage.Information);
        Shutdown();
        return;
    }
    base.OnStartup(e);
    // ... 기존 로직
}
```

**의도된 한계 (보안 기능 아님):**
- 시스템 시계 조작(BIOS/제어판) 우회 가능 — 운영 가이드용
- 만료 시점에 백엔드 서버 연결 검증은 하지 않음 (오프라인 환경 고려)

### 변경 ② — WebView2 우클릭 컨텍스트 메뉴 제한
**파일:** `src/Aitty/MainWindow.xaml.cs`

- `ConfigureContextMenu()` 헬퍼 신설.
- `InitializeWebView2Async`의 3회 재시도 모두 성공 분기에서 호출 → 누락 없음.
- `CoreWebView2.ContextMenuRequested` 이벤트에서 `MenuItems` 컬렉션을 역순 순회하며 `Name`이 `"copy"` / `"paste"` 외 모든 항목 `RemoveAt`.

```csharp
private void ConfigureContextMenu()
{
    webView.CoreWebView2.ContextMenuRequested += (_, args) =>
    {
        var items = args.MenuItems;
        for (int i = items.Count - 1; i >= 0; i--)
        {
            var name = items[i].Name;
            if (!string.Equals(name, "copy", StringComparison.OrdinalIgnoreCase)
                && !string.Equals(name, "paste", StringComparison.OrdinalIgnoreCase))
            {
                items.RemoveAt(i);
            }
        }
    };
}
```

**제거되는 항목 (스크린샷 기준):**
- 뒤로 (Alt+←) / 새로 고침 (Ctrl+R) / 다른 이름으로 저장 / 인쇄 (Ctrl+P) / 기타 도구 / 검사 (DevTools)

**유지되는 항목:** 복사하기 (Ctrl+C), 붙여넣기 (Ctrl+V)

### 결정 사항
1. **PATCH (0.4.1 → 0.4.2)** — 사용자 인지 변화 있는 추가지만 작은 범위라 PATCH 채택(Owner 결정). MINOR(0.5.0)도 가능했음.
2. **base.OnStartup 전 만료 체크** — MainWindow 생성·초기화 비용 차단. 만료 후에는 진단 로그도 남기지 않음(의도).
3. **ContextMenuRequested 화이트리스트 방식** — WebView2 표준 항목명(`copy`/`paste`)만 유지. 향후 새 항목이 추가돼도 자동 차단(failsafe).

### 이슈 / 특이사항
- **WebView2 표준 ContextMenuItem.Name 값**: 공식 문서 기준 `copy`, `paste`, `cut`, `selectAll`, `back`, `forward`, `reload`, `saveAs`, `print`, `more`, `inspect` 등. 우리는 `copy`/`paste`만 허용.
- **`cut`(잘라내기)는 제외함** — 사용자 요청이 "복사하기, 붙여넣기만 허용"이라 명시. 필요 시 화이트리스트에 `cut` 추가만 하면 됨.
- **OnStartup의 `Shutdown()` 호출 안전성**: WPF는 StartupUri 처리(MainWindow 생성)를 base.OnStartup 내부에서 수행 → 우리 가드는 base 호출 *전*이므로 안전.
