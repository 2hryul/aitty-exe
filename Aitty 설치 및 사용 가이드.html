1. Aitty 소개 — 무엇을 하는 도구인가

SSH 터미널 + AI Agent로 터미널 화면을 해석하고, 사용자에게 명령어를 추천하는 Windows 데스크톱 앱
arty
01

PuTTY 호환 SSH 터미널

비밀번호·키 인증, 프리셋 저장, xterm 기반 풀 터미널. HiWare 같은 접근제어 솔루션이 PuTTY 대신 호출해도 그대로 동작합니다.

02

4-Provider AI 분석

Ollama(로컬) · OpenAI 호환 사내 게이트웨이 · Claude · Gemini 중 선택. 터미널 출력을 그대로 넘겨 원인과 조치를 받습니다.

03

CLI 모드 · 내장 명령

AI 터미널에서 status · model use · analyze last 같은 명령으로 키보드만으로 모델 전환과 분석을 합니다.

04

프리셋 · 키 보호

AI 접속 정보를 프리셋으로 저장해 고르기만 하면 되고, API 키는 Windows DPAPI로 암호화합니다. SSH 비밀번호는 저장하지 않습니다.

4. SSH 접속과 AI 활용 

처음 한 번 AI 제공자를 설정해 두면, 접속 → 명령 실행 → AI분석 흐름으로 바로 씁니다
arty
STEP 1AI 설정 (최초 1회)

⚙ → Provider 선택 → 엔드포인트·API 키 입력 → Check로 연결 확인 → Apply. 프리셋으로 저장하면 다음부터 선택만 하면 됩니다. API 키는 Windows DPAPI로 암호화해 보관합니다.

STEP 2서버 접속

Host · Port · 계정 · 비밀번호(또는 개인키) 입력 후 Connect 또는 Enter. 처음 접속하는 서버는 호스트 키를 기억(TOFU)하고, 이후 키가 바뀌면 경고합니다. 비밀번호는 저장되지 않습니다.

HiWare 등에서 PuTTY 대신 Aitty.exe를 지정하면 접속 정보를 인자로 받아 자동 접속됩니다.
STEP 3AI분석 · 질문

df -h, tail -n 200 error.log처럼 평소대로 명령을 치고 AI분석을 누르면 마지막 출력을 읽고 원인·영향·권장 조치를 답합니다. 채팅창에는 자유롭게 질문할 수 있고, 명령 제안도 받을 수 있습니다.

CLI 탭 내장 명령어 — AI 터미널에서 직접 입력
명령어기능
statusAI 엔진 연결 상태 확인
model list / model use 모델명사용 가능한 모델 목록 · 모델 전환
analyze lastSSH 마지막 출력 분석 (AI분석 버튼과 동일)
system set 프롬프트 · reset시스템 프롬프트 변경 · 대화 이력 초기화
알아두면 좋은 것
  • 사내 게이트웨이가 스트리밍(SSE)을 지원하지 않으면 자동으로 일반 응답으로 전환됩니다. 응답이 조금 늦게 한 번에 옵니다.
  • AI 응답 생성 중 Ctrl+C로 취소, Ctrl+L로 화면 지우기, Ctrl+Q 종료.
  • 프리셋은 사용자 암호로 암호화해 다른 PC로 옮길 수 있습니다 (설정 → 프리셋 내보내기).
