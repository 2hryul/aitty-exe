## 🐛 버그 수정

### 4. WebView2 `0x8007139F` 초기화 실패 복구 — CRITICAL

**파일**: `src/Aitty/MainWindow.xaml.cs` (+63 LoC)

**근본 원인**: WebView2 비정상 종료 후 `EBWebView/SingletonLock` 잔류 → 다음 실행 시 `0x8007139F` COMException으로 앱 시작 불가

**3단계 복구 전략** (`InitializeWebView2Async()`):
```
Attempt 0: 정상 초기화 시도
  └─ COMException → CleanWebView2LockFiles() → 1.5초 대기
Attempt 1: 잠금 파일 정리 후 재시도
  └─ COMException → 새 폴더 WebView2_{yyyyMMdd_HHmmss}
Attempt 2: 격리 폴더에서 초기화
  └─ 실패 → 예외 전파 (기존 catch에서 처리)
```

**잠금 파일 정리 대상** (`CleanWebView2LockFiles()`):
- `EBWebView/*lock*` (SingletonLock 등)
- `EBWebView/*.tmp`

### 5. AI 스트리밍 최종 청크 유실 — IMPORTANT

**파일**: `src/Aitty/Ipc/IpcHandler.cs`

**근본 원인**: `InvokeAsync(DispatcherPriority.Background)` fire-and-forget 패턴에서 스트리밍 완료 응답이 마지막 Background 청크보다 먼저 React에 도달 → 불완전한 응답 표시 (빈 말풍선)

**수정**: 3개 스트리밍 핸들러에 `lastChunkOp` 추적 + 완료 전 await 패턴 적용

```csharp
// HandleAiStream, HandleAiAnalyzeSsh, HandleAiSuggestCommand 공통 패턴
DispatcherOperation? lastChunkOp = null;

var response = await _aiManager.Active.SendStreamingAsync(prompt, chunk =>
{
    var json = JsonSerializer.Serialize(chunkResponse, JsonOptions);
    lastChunkOp = _webView.Dispatcher.InvokeAsync(
        () => _webView.CoreWebView2.PostWebMessageAsJson(json),
        DispatcherPriority.Background);
});

// Background 큐는 FIFO — 마지막 청크 완료 = 이전 청크 모두 전달 완료
if (lastChunkOp is not null)
    try { await lastChunkOp.Task.ConfigureAwait(false); } catch { }
```

### 6. Chat 패널 렌더링 스로틀 (80ms 배치)

**파일**: `webapp/src/hooks/useAITerminal.ts`

**문제**: 스트리밍 청크마다 `setChatMessages()` → React re-render → 초당 50~100회 DOM 업데이트

**수정**: 80ms 타이머 기반 배치 처리. 스트리밍 종료 시 잔여 타이머 `clearTimeout` + 최종 상태 1회 반영(content + isStreaming=false 동시).

```typescript
let chatUpdateTimer: ReturnType<typeof setTimeout> | null = null
ai.stream(message, (chunk) => {
  contentRef.current += chunk
  if (chatUpdateTimer === null) {
    chatUpdateTimer = setTimeout(() => {
      chatUpdateTimer = null
      setChatMessages(prev => prev.map(m =>
        m.id === assistantId ? { ...m, content: contentRef.current } : m))
    }, 80)
  }
})
```

**효과**: re-render 횟수 ~12.5회/초로 감소 (기존 50~100회/초 → **~80% 절감**)
