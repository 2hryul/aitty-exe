## 🐛 버그 수정

### WebView2 초기화 실패 (`0x8007139F`) 대응

**파일**: `src/Aitty/MainWindow.xaml.cs`

**증상**: 앱 재시작 시 간헐적으로 WebView2 초기화 실패 → 앱 크래시
```
COMException: 0x8007139F — The group or resource is not in the correct state
```

**원인**: 이전 프로세스가 비정상 종료되면 `%LOCALAPPDATA%\Aitty\WebView2\EBWebView\SingletonLock` 등 잠금 파일이 잔류 → 다음 실행 시 WebView2가 해당 폴더를 점유 불가

**수정**: `InitializeWebView2Async()` 메서드 분리 — 3단계 복구 전략 적용

```csharp
private async Task InitializeWebView2Async(string baseDataFolder)
{
    var userDataFolder = Path.Combine(baseDataFolder, "WebView2");

    for (int attempt = 0; attempt < 3; attempt++)
    {
        try
        {
            Directory.CreateDirectory(userDataFolder);
            var env = await CoreWebView2Environment.CreateAsync(null, userDataFolder);
            await webView.EnsureCoreWebView2Async(env);
            return; // 성공
        }
        catch (COMException ex) when (attempt < 2)
        {
            if (attempt == 0)
            {
                // 1차 실패: 잠금 파일 정리 후 1.5초 대기 → 재시도
                CleanWebView2LockFiles(userDataFolder);
                await Task.Delay(1500);
            }
            else
            {
                // 2차 실패: 새 타임스탬프 폴더로 폴백
                userDataFolder = Path.Combine(baseDataFolder, $"WebView2_{DateTime.Now:yyyyMMdd_HHmmss}");
            }
        }
    }
    // 3차 시도 (예외 시 상위 catch로 전파)
    ...
}
```

**복구 흐름**:

```
앱 시작
  ↓
WebView2/EBWebView/SingletonLock 존재?
  ├─ 없음: 정상 초기화
  └─ 있음: COMException 0x8007139F
       ↓
       [1차] CleanWebView2LockFiles() — *lock*, *.tmp 파일 삭제
       → 1.5초 대기 → 재시도
         ├─ 성공 → 정상 동작
         └─ 실패 → [2차] WebView2_20260325_093045 신규 폴더로 폴백 → 재시도
              └─ 실패 → 예외 전파 (기존 동작)
```

**CleanWebView2LockFiles()**:
```csharp
// EBWebView 폴더 내 *lock*, *.tmp 파일만 선택적 삭제
// 사용자 데이터(히스토리, 캐시 등)는 보존
foreach (var lockFile in Directory.GetFiles(ebWebView, "*lock*", SearchOption.TopDirectoryOnly))
    File.Delete(lockFile);
foreach (var lockFile in Directory.GetFiles(ebWebView, "*.tmp", SearchOption.TopDirectoryOnly))
    File.Delete(lockFile);
```
